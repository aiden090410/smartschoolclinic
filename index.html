스마트 보건실 (LABIT) 사용 설명서

보건실 방문 접수 및 대기열 관리 시스템 매뉴얼

# 1. 프로그램 소개

스마트 보건실 통합 관리 시스템 (LABIT)의 개요 및 제작 목적

학교 보건실의 접수 및 대기 과정을 효율적으로 관리하기 위해 제작된 보건실 방문 접수 및 대기열 관리 프로그램이다.

학생은 보건실에 방문하기 전 프로그램을 통해 방문 목적과 현재 상태를 선택하여 접수할 수 있으며, 접수 후 발급되는 대기번호를 통해 자신의 대기 순서를 확인할 수 있다.

관리자는 별도의 관리자 화면에서 학생들의 접수 현황을 확인하고, 방문 목적별 대기열을 관리할 수 있다. 또한 누적된 접수 데이터를 바탕으로 방문 유형과 시간대별 통계를 확인할 수 있다.

## 이용 대상

  • 학생 보건실 방문 전 접수를 진행하고 대기번호를 발급받는 사용자
  • 보건실 담당 교사 학생들의 접수 현황과 대기열을 확인하고 접수 상태를 관리하는 사용자

## 제작 목적

쉬는 시간이나 점심시간처럼 보건실 방문이 집중되는 시간에는 접수와 대기가 혼잡해질 수 있다.

LABIT은 방문 목적별 접수와 대기열 분리를 통해 이러한 혼잡을 줄이고, 보건실 담당 교사가 학생들의 방문 현황을 보다 효율적으로 파악할 수 있도록 돕는 것을 목적으로 한다.

# 2. 접속 및 설치 방법

웹 브라우저 접속 및 PWA(Progressive Web App) 앱 설치 가이드

## 프로그램 접속

  1. 제공된 프로그램 접속 주소에 접속한다.
  2. 프로그램의 메인 화면이 정상적으로 표시되는지 확인한다.
  3. 학생은 학생용 접수 기능을 이용하고, 보건실 담당 교사는 [🔑 교사 로그인] 기능을 이용한다.

## PWA 설치 방법

이 프로그램은 PWA(Progressive Web App) 방식으로 제작되어 지원되는 브라우저와 기기에서 앱처럼 설치하여 사용할 수 있다.

💻 PC에서 설치하기

  1. Chrome 또는 지원되는 브라우저에서 프로그램에 접속한다.
  2. 주소창 주변에 표시되는 설치 아이콘 또는 브라우저 메뉴의 설치 항목을 선택한다.
  3. 설치 안내가 나타나면 설치를 진행한다.
  4. 설치가 완료되면 바탕화면이나 앱 목록에서 프로그램을 실행할 수 있다.

📱 모바일 및 태블릿에서 설치하기

  1. 브라우저에서 프로그램에 접속한다.
  2. 브라우저 메뉴에서 '홈 화면에 추가' 또는 '앱 설치' 항목을 선택한다.
  3. 설치를 진행한다.
  4. 홈 화면에 생성된 프로그램 아이콘을 눌러 실행한다.
※ 브라우저와 운영체제에 따라 설치 메뉴의 명칭과 제공 여부가 다를 수 있다.

# 3. 화면 구성 설명

학생용 접수 화면, 교사 관리자 화면, 방문 통계 화면 UI 안내

### 3-1. 학생용 화면

  • [Touch ! 접수 시작하기] 버튼: 보건실 방문 접수를 시작한다.
  • 방문 목적 선택 버튼: 보건실을 방문하는 목적(5가지 카테고리)을 선택한다.
  • 상태 및 증상 선택 버튼: 현재 상태나 증상에 해당하는 세부 항목을 선택한다.
  • [✅ 최종 접수 확정] 버튼: 선택한 정보를 바탕으로 접수를 요청한다.
  • 대기번호 표시 영역: 접수가 정상적으로 완료되면 발급된 대기번호(예: A-01)를 표시한다.
  • [❌ 접수 취소하기] 버튼: 진행 중인 접수를 취소하거나 이전 화면으로 돌아간다.

### 3-2. 관리자 화면

  • 로그인 입력란: 관리자 인증에 필요한 비밀번호(admin1234)를 입력한다.
  • [로그인] 버튼: 입력한 정보로 관리자 인증을 진행한다.
  • 대기열 목록 & 칸반 보드: 방문 목적별로 접수된 학생들의 대기 현황을 보여준다.
  • 접수 상세 정보: 선택한 접수의 방문 목적과 입력 정보를 확인한다.
  • 상태 변경 버튼: 접수 상태를 대기 중, 상담 중, 완료 등으로 변경한다.
  • 취소 기능: 해당 접수를 취소 처리한다.
  • [🔄 새로고침] 버튼: 최신 접수 현황을 다시 불러온다.
  • [방문 통계] 메뉴: 접수 데이터를 바탕으로 계산된 통계 정보를 확인한다.
  • [관리자 로그아웃] 버튼: 관리자 화면에서 안전하게 로그아웃한다.

### 3-3. 통계 화면

  • 전체 접수 건수: 조회 기간에 해당하는 전체 접수 현황을 보여준다.
  • 방문 목적별 통계: 방문 목적에 따른 접수 건수와 비율(도넛 그래프)을 보여준다.
  • 날짜별 통계: 날짜에 따른 접수량의 변화(선 그래프)를 보여준다.
  • 시간대별 통계: 특정 시간대에 접수가 얼마나 발생했는지(막대 그래프) 보여준다.
  • 상태별 통계: 대기, 상담, 완료, 취소 상태에 따른 접수 현황을 보여준다.
  • 기간 선택 기능: 원하는 기간(전체, 오늘, 7일, 30일)을 지정하여 통계 데이터를 조회한다.

# 4. 기능별 사용 방법

학생 접수, 관리자 대기열 제어, 통계 조회 3가지 주요 순서 가이드

기능 ① 학생용 보건실 방문 접수

학생이 보건실을 방문하기 전에 자신의 방문 목적과 상태를 선택하고 대기번호를 발급받는 기능이다.

【 사용 순서 】

  1. 메인 화면에 접속한다.
  2. [Touch ! 접수 시작하기] 버튼을 눌러 학생용 접수 화면으로 이동한다.
  3. 학년/반/번호/이름 정보를 입력 후 화면에 표시된 방문 목적(5가지) 중 자신의 방문 목적에 해당하는 항목을 선택한다.
  4. 현재 상태나 증상에 해당하는 세부 항목을 선택한다.
  5. 선택한 내용이 맞는지 접수 내역을 확인한다.
  6. [✅ 최종 접수 확정] 버튼을 눌러 접수를 요청한다.
  7. 접수가 정상적으로 처리되면 화면에 표시되는 대기번호(예: A-01)를 확인한다.
  8. 발급된 대기번호를 확인하고 보건실 담당 교사의 안내에 따라 대기한다.
📌 이용 시 참고사항
  • 방문 목적은 실제 방문 이유와 가장 가까운 항목을 선택한다.
  • 증상이나 상태를 선택하는 과정은 접수 정보를 전달하기 위한 것이며 의료적 진단을 의미하지 않는다.
  • 접수가 완료되었다는 표시가 나타나지 않았다면 접수 여부를 다시 확인한다.
  • 긴급하거나 즉각적인 도움이 필요한 경우 프로그램 접수만 기다리지 말고 보건실 담당 교사에게 직접 알린다.

기능 ② 관리자 대기열 관리

보건실 담당 교사가 학생들의 접수 현황을 확인하고 방문 목적별 대기열을 관리하는 기능이다.

【 사용 순서 】

  1. 프로그램에 접속한다.
  2. 우측 상단 [🔑 교사 로그인] 버튼을 눌러 관리자 로그인 화면으로 이동한다.
  3. 관리자 인증 정보(비밀번호: admin1234)를 입력하고 로그인한다.
  4. 관리자 대시보드에서 현재 접수 현황을 확인한다.
  5. 방문 목적별로 구분된 대기열(칸반 보드)을 확인한다.
  6. 관리할 접수 항목을 선택하여 상세 정보를 확인한다.
  7. 학생의 상담 진행 상황에 따라 접수 상태를 변경한다.
대기 중: 접수가 완료되었으며 아직 상담이 시작되지 않은 상태
상담 중: 담당 교사가 해당 학생을 확인하거나 상담하고 있는 상태
완료: 해당 접수에 대한 처리가 끝난 상태
취소: 접수가 취소된 상태
📌 이용 시 참고사항
  • 학생의 실제 방문 목적과 접수 정보가 일치하는지 확인한다.
  • 방문 목적별 대기열을 구분하여 확인한다.
  • 상담이 시작되면 해당 접수를 [상담 시작]으로 변경한다.
  • 처리가 끝나면 [완료 처리] 상태로 변경한다.
  • 취소된 접수는 정상적인 완료 건수와 구분하여 관리한다.
  • 관리자 화면을 사용한 뒤에는 반드시 [관리자 로그아웃]을 진행한다.

기능 ③ 접수 통계 확인

누적된 접수 데이터를 바탕으로 보건실 방문 현황을 수치와 그래프로 확인하는 기능이다.

【 사용 순서 】

  1. 관리자 계정으로 로그인한다.
  2. 관리자 대시보드 상단 탭에서 [방문 통계] 메뉴로 이동한다.
  3. 전체 접수 건수와 주요 통계 수치(KPI 카드)를 확인한다.
  4. 방문 목적별 접수 건수와 비율(도넛 그래프)을 확인한다.
  5. 날짜별 접수 추이(선 그래프)를 확인한다.
  6. 시간대별 접수 현황(막대 그래프)을 확인한다.
  7. 상태별(완료/대기/취소) 접수 건수를 확인한다.
  8. 필요한 경우 조회 기간(전체/오늘/7일/30일)을 변경하여 원하는 기간의 통계를 확인한다.
📊 통계 활용 방법 및 원칙

통계는 Google Sheets에 저장된 접수 데이터를 일반적인 데이터 집계 방식으로 계산한 결과이며, AI 분석이나 의료적 판단을 제공하지 않는다.

# 5. 주의사항 및 자주 묻는 질문

안전한 시스템 이용을 위한 수칙 및 FAQ 답변 모음

⚠️ 반드시 알아야 할 핵심 주의사항

  1. 학생은 실제 방문 목적과 가장 가까운 항목을 선택해야 한다.
  2. 접수 완료 여부와 발급된 대기번호를 반드시 확인해야 한다.
  3. 접수 도중 인터넷 연결이 끊기면 서버에 데이터가 정상적으로 저장되지 않았을 수 있으므로 접수 상태를 확인해야 한다.
  4. 인터넷 연결이 필요한 접수 및 관리자 기능은 오프라인 상태에서 정상적으로 작동하지 않을 수 있다.
  5. 관리자 계정 정보는 다른 학생이나 외부인에게 공유하지 않는다.
  6. 관리자 작업이 끝나면 반드시 로그아웃한다.
  7. 본 프로그램은 접수 및 대기열 관리를 위한 프로그램이며 의료적 진단이나 응급상황 판단을 대신하지 않는다.
  8. 긴급한 상황에서는 프로그램 사용보다 보건실 담당 교사에게 직접 도움을 요청하는 것이 우선이다.

## 자주 묻는 질문 (FAQ)

Q1 접수했는데 대기번호가 표시되지 않아요.
인터넷 연결 상태를 확인하고 접수가 정상적으로 완료되었는지 확인한다. 서버 오류가 발생했을 가능성이 있으므로 중복 접수하기 전에 보건실 담당 교사에게 문의한다.
Q2 잘못된 방문 목적을 선택했어요.
접수가 완료되기 전이라면 [수정하기] 또는 [이전] 버튼을 눌러 다시 선택한다. 이미 접수가 완료되었다면 보건실 담당 교사에게 수정이 필요한 부분을 알린다.
Q3 대기번호는 어떻게 확인하나요?
접수가 정상적으로 완료된 직후 표시되는 접수 완료 화면에서 확인할 수 있다.
Q4 인터넷이 연결되지 않아도 사용할 수 있나요?
앱의 일부 화면은 표시될 수 있지만 접수 저장이나 관리자 데이터 조회 등 서버 통신이 필요한 기능은 인터넷 연결이 필요하다.
Q5 관리자는 어떤 정보를 확인할 수 있나요?
접수된 학생의 학년/반/번호/이름, 방문 목적과 선택한 상태 정보, 대기 현황 및 접수 처리 상태를 확인할 수 있다.
Q6 통계 데이터는 어떻게 만들어지나요?
Google Sheets에 저장된 접수 데이터를 바탕으로 프로그램이 직접 일반 수치 집계 방식으로 계산한다.
Q7 접수가 취소되면 어떻게 되나요?
관리자 화면에서 해당 접수를 취소 상태로 변경할 수 있다. 취소된 접수는 완료된 접수와 구분하여 관리한다.
Q8 앱 설치 없이도 사용할 수 있나요?
가능하다. 웹 브라우저에서 프로그램 접속 주소를 열어 바로 사용할 수 있다.
